# Латышский тренажёр

Веб-приложение для изучения латышских слов: чистые HTML + CSS + JS, без сборки.

## Запуск

Браузеры не дают странице, открытой двойным кликом (`file://`), читать `data/*.json`.
Поэтому есть три варианта:

- **GitHub Pages** — основной вариант (см. ниже).
- **Локальный сервер** в папке проекта: `python -m http.server 8000` → http://localhost:8000
  (или Live Server в VS Code / встроенный сервер IntelliJ).
- **Двойной клик по index.html** — приложение покажет кнопку «Выбрать файлы из папки data»,
  и слова загрузятся на эту сессию.

Распознавание речи работает только по https или на localhost.

## Публикация на GitHub Pages

Публикует workflow `.github/workflows/pages.yml`: при каждом пуше в `main` он гоняет тесты
и, если они прошли, выкладывает сайт. Один раз в репозитории на GitHub:
Settings → Pages → Source: **GitHub Actions**.

Адрес: `https://<логин>.github.io/<репозиторий>/`.

## Структура

```
index.html
css/style.css
js/util.js     — сравнение ответов, разбор JSON, даты
js/stats.js    — подбор слов, периоды, сводка и текст отчёта (без DOM)
js/store.js    — данные, журнал, импорт/экспорт, система Лейтнера, дни подряд
js/speech.js   — озвучка и распознавание lv-LV
js/app.js      — экраны и режимы
data/words.json, data/texts.json
tests/run.js   — тесты: node tests/run.js
```

## Как устроено повторение

- Ящики 1–5. Новое слово лежит в ящике 1. Верно — ящик выше, ошибка — в ящик 1,
  «почти» (ошибка только в диакритике) — слово остаётся на месте.
- В сессию слова попадают случайно, но с весом: ящик 1 — 16, 2 — 8, 3 — 4, 4 — 2, 5 — 1.
- Плюс последние 80 ответов: за каждую ошибку штраф 1, за «почти» 0.5,
  вес умножается на (1 + 2 × штраф). Одна свежая ошибка — слово выпадает втрое чаще.
- «Всё пройденное» = все слова из данных. Файлы и импорт дополняются по мере прохождения уроков.

## Импорт

На экране «Импорт» можно вставить массив слов и/или текстов (формат как в `data/`).
Записи с уже существующим `id` обновляются. Импортированное лежит в localStorage
и накладывается поверх файлов. Туда же можно вставить резервную копию из «Экспорта»:
слова, тексты и (по подтверждению) прогресс восстановятся.

## Журнал и статистика

- Каждый ответ пишется в журнал (`lv.log` в localStorage): id слова, режим, что введено,
  результат, время и сколько секунд думал. Журнал не чистится и входит в экспорт.
- Статистика за сегодня / 7 дней / 30 дней / всё время: точность по блокам и урокам,
  трудные слова, ошибки «Ввода» (только диакритика / другие / «не знаю»).
- «Начать с нуля» ставит отметку времени: статистика и отчёт считаются от неё, журнал остаётся.
  «Сбросить ящики» обнуляет Лейтнера, журнал тоже остаётся.
- «Скопировать отчёт» — текстовый отчёт за выбранный период со сравнением с предыдущим таким же.
  Если буфер обмена недоступен (не https), текст появляется в поле для ручного копирования.

## Тесты

```
node tests/run.js
```

Без зависимостей. Проверяют сравнение ответов, подбор слов, периоды, сводку, отчёт и журнал.
